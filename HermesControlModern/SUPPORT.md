# Support

Use GitHub Issues for reproducible bugs and focused feature requests.

Before filing an issue:

1. Confirm that Hermes or OpenClaw works from the same local shell used by the controller.
2. Confirm that the configured Lab Root and Hermes Home paths exist.
3. Confirm that the relevant `systemd --user` gateway service exists.
4. Remove all tokens, private profile configuration, and personal paths from logs.

The project does not provide emergency support or uptime guarantees. Keep independent access to gateway service controls when operating unattended agents.
