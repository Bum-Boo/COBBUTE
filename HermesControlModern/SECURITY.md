# Security Policy

## Supported versions

Security fixes are provided for the latest published release and current prerelease.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting:

https://github.com/Bum-Boo/COBBUTE/security/advisories/new

Do not open a public issue for a suspected vulnerability. Do not include real Discord, Telegram, OpenAI, Anthropic, or signing credentials in any report. Replace credentials and user-specific paths with redacted placeholders.

Include the controller version, operating system, reproduction steps, impact, and a minimal sanitized log when available.
